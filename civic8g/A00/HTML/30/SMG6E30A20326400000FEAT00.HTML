Fuel Pressure Test

Special Tools Required
Fuel pressure gauge (  07406-0040004)
 

Fuel pressure gauge set (  07ZAJ-S5A0100)
 
Fuel hose attachment E set (  070AJ-SEA0100)
 



1.Relieve the fuel pressure.

2.Disconnect the quick-connect fitting (A) at the fuel rail (B).

 

3.Install the fuel hose attachment E set to the fuel rail and quick-connect fitting. Attach the fuel pressure gauge set and the fuel pressure gauge.

4.Start the engine and let it idle.

  • If the engine starts, go to 6.
  • If the engine does not start, go to 5.

5.Check to see if the fuel pump is running: listen to the fuel filler port with the fuel fill cap removed. The fuel pump should run for 2 seconds when the ignition switch is first turned on.

  • If the pump runs, go to 6.
  • If the pump does not run, do the fuel pump circuit troubleshooting.

6.Read the fuel pressure gauge. The pressure should be 320-370 kPa (3.3-3.8 kgf/cm2, 47-54 psi).

  • If the pressure is OK, the test is complete.
  • If the pressure is out of specification, replace the fuel pressure regulator and the fuel filter, then recheck the fuel pressure.
