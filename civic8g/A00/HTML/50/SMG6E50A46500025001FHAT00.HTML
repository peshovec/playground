Engine Start Switch Test/Replacement

1.Remove the driver's undercover.

2.Disconnect the 5P connector (A), then remove the engine start switch (B).

 

3.Check for continuity between the No. 1 and No. 2 terminals of the engine start switch. There should be continuity with the switch pressed.

  • If there is continuity, go to 4.
  • If there is no continuity, replace the engine start switch.

 

4.Check for continuity between the No. 4 and No. 5 terminals of the engine start switch. There should be continuity in only one direction.

  • If there is continuity in only one direction, go to 5.
  • If there is continuity in both directions or no continuity in both directions, replace the engine start switch.

5.Install the engine start switch in the reverse order of removal.
