DTC Troubleshooting: P0503 (17-3)

DTC P0503:  Output Shaft (Countershaft) Speed Sensor Signal Malfunction


NOTE: Before you troubleshoot, record all freeze data and review the general troubleshooting information.

1.Clear the DTC with the HDS.

2.Start the engine, then let it idle.

3.Check for Temporary DTCs or DTCs with the HDS.

Is DTC P0503 indicated?


YES - Go to 6.


NO - Go to 4.


4.Test-drive the vehicle for several minutes in the range of the recorded freeze data.

5.Check for Temporary DTCs or DTCs with the HDS.

Is DTC P0503 indicated?


YES - Go to 6.


NO - Intermittent failure, system is OK at this time. Check for poor connections or loose terminals at the output shaft (countershaft) speed sensor and the ECM.n


6.Reset the ECM with the HDS.

7.Check for poor or loose connections and terminals at the following:
  • Output shaft (countershaft) speed sensor
  • ECM
  • Engine ground
  • Body ground

Are the connections and terminals OK?


YES - Go to 8.


NO - Repair the connectors or terminals, then go to 9.

8.Replace the output shaft (countershaft) speed sensor.

9.Turn the ignition switch ON (II).

10.Reset the ECM with the HDS.

11.Start the engine, then let it idle.

12.Check for Temporary DTCs or DTCs with the HDS.

Is DTC P0503 indicated?


YES - Go to 15.


NO - Go to 13.


13.Test-drive the vehicle for several minutes in the range of these recorded freeze data parameters:
  • ENGINE SPEED
  • VSS

14.Check for Temporary DTCs or DTCs with the HDS.

Is DTC P0503 indicated?


YES - Go to 15.


NO - Troubleshooting is complete.n


15.Update the ECM if it does not have the latest software, or substitute a known-good ECM.

16.Start the engine, then let it idle.

17.Check for Temporary DTCs or DTCs with the HDS.

Is DTC P0503 indicated?


YES - If DTC P0503 is indicated, check for poor connections or loose terminals at the output shaft (countershaft) speed sensor and the ECM, then go to 1. If any other Temporary DTCs or DTCs are indicated, go to the indicated DTC's troubleshooting.


NO - Go to 18.

18.Test-drive the vehicle for several minutes in the range of these recorded freeze data parameters:
  • ENGINE SPEED
  • VSS

19.Check for Temporary DTCs or DTCs with the HDS.

Is DTC P0503 indicated?


YES - If DTC P0503 is indicated, check for poor connections or loose terminals at the output shaft (countershaft) speed sensor and the ECM, then go to 1. If any other Temporary DTCs or DTCs are indicated, go to the indicated DTC's troubleshooting.


NO - If the ECM was updated, troubleshooting is complete. If the ECM was substituted, replace the original ECM.n
