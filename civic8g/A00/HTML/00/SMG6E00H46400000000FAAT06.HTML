SRS Symptom Troubleshooting - Faulty seat belt reminder light

Faulty seat belt reminder light


1.Observe these precautions:

  • Unbuckle the left side seat belt.
  • Unbuckle the right side seat belt.
  • Make sure nothing is on or under the seat.

2.Connect the HDS to the DLC located under driver's side of the dashboard.

3.Turn the ignition switch ON (II).

4.Make sure the HDS communicates with the vehicle and the SRS unit. If it does not troubleshoot the DLC circuit.

5.From the Main Menu on the HDS, select SRS, then PARAMETER INFORMATION. In the PARAMETER INFORMATION Menu, select ‘‘SRS FRBKLSW'', and read the HDS indicated.

Is ‘‘OFF'' indicated?


YES - Go to 8.


NO - Go to 6.


6.Disconnect the floor wire harness 3P connector from the right side seat belt buckle switch 3P connector (A).

 

7.From the Main Menu on the HDS, select SRS, then PARAMETER INFORMATION. In the PARAMETER INFORMATION Menu, select ‘‘SRS FRBKLSW'', and read the HDS indicated.

Is ‘‘ON'' indicated?


YES - Short to ground in the floor wire harness; replace the floor wire harness.n


NO - Faulty right side seat belt buckle switch.


8.From the Main Menu on the HDS, select SRS, then PARAMETER INFORMATION. In the PARAMETER INFORMATION Menu, select ‘‘SRS FLBKLSW'', and read the HDS indicated.

Is ‘‘OFF'' indicated?


YES - Go to 11.


NO - Go to 9.


9.Disconnect the floor wire harness 3P connector from the left side seat belt buckle switch 3P connector (A).

 


10.From the Main Menu on the HDS, select SRS, then PARAMETER INFORMATION. In the PARAMETER INFORMATION Menu, select ‘‘SRS FLBKLSW'', and read the HDS indicated.

Is ‘‘ON'' indicated?


YES - Short to ground in the floor wire harness; replace the floor wire harness.n


NO - Faulty left side seat belt buckle switch.n

11.From the Main Menu on the HDS, select SRS, then PARAMETER INFORMATION. In the PARAMETER INFORMATION Menu, select ‘‘SRS PASS'', and read the HDS indicated.

Is ‘‘OFF'' indicated?


YES - Go to 14.


NO - Go to 12.


12.Disconnect the floor wire harness 2P connector from the front passenger's seat sitting switch.

 

13.From the Main Menu on the HDS, select SRS, then PARAMETER INFORMATION. In the PARAMETER INFORMATION Menu, select ‘‘SRS PASS'', and read the HDS indicated.

Is ‘‘ON'' indicated?


YES - Short to ground in the floor wire harness; replace the floor wire harness.


NO - Faulty front passenger's seat sitting switch.n

14.Check the seat belt reminder light.

Does the seat belt reminder light stay on?


YES - Go to 15.


NO - Carry out ‘‘SELF TEST'' with HDS. If seat belt reminder light does not stay on, replace the gauge control module.n


15.Observe these precautions:

  • Unbuckle the left side seat belt.
  • Unbuckle the right side seat belt.
  • I make it the state that people more than 45 kg in weight sit down on in front passenger's seat.

16.From the Main Menu on the HDS, select SRS, then PARAMETER INFORMATION. In the PARAMETER INFORMATION Menu, select ‘‘SRS FRBKLSW'', and read the HDS indicated.

Is ‘‘ON'' indicated?


YES - Go to 23.


NO - Go to 17.


17.Disconnect the floor wire harness 3P connector from the right side seat belt buckle switch 3P connector (A).

 

18.Install a jumper wire between the No. 1 terminal and the No. 2 terminal of the floor wire harness 3P connector.

19. From the Main Menu on the HDS, select SRS, then PARAMETER INFORMATION. In the PARAMETER INFORMATION Menu, select ‘‘SRS FRBKLSW'', and read the HDS indicated.

Is ‘‘ON'' indicated?


YES - Faulty right side seat belt buckle switch.n


NO - Go to 20.


20.Reinstall a jumper wire between the No. 1 terminal and the No. 2 terminal of the floor wire harness 3P connector.

21.Install a jumper wire between the No. 1 terminal of the floor wire harness and body ground.

22.From the Main Menu on the HDS, select SRS, then PARAMETER INFORMATION. In the PARAMETER INFORMATION Menu, select ‘‘SRS FRBKLSW'', and read the HDS indicated.

Is ‘‘ON'' indicated?


YES - Open in between the No. 1 terminal of right side seat belt buckle switch and body ground.n


NO - Open in between the No. 2 terminal of right side seat belt buckle switch and No. 15 terminal of SRS unit connector B (28P).n


23.From the Main Menu on the HDS, select SRS, then PARAMETER INFORMATION. In the PARAMETER INFORMATION Menu, select ‘‘SRS FLBKLSW'', and read the HDS indicated.

Is ‘‘ON'' indicated?


YES - Go to 30.


NO - Go to 24.

24.Disconnect the floor wire harness 3P connector from the left side seat belt buckle switch 3P connector (A).

 

25.Install a jumper wire between the No. 1 terminal and the No. 2 terminal of the floor wire harness 3P connector.

26.From the Main Menu on the HDS, select SRS, then PARAMETER INFORMATION. In the PARAMETER INFORMATION Menu, select ‘‘SRS FLBKLSW'', and read the HDS indicated.

Is ‘‘ON'' indicated?


YES - Faulty left side seat belt buckle switch.n


NO - Go to 27.


27.Reinstall a jumper wire between the No. 1 terminal and the No. 2 terminal of the floor wire harness 3P connector.

28.Install a jumper wire between the No. 1 terminal of the floor wire harness and body ground.

29.From the Main Menu on the HDS, select SRS, then PARAMETER INFORMATION. In the PARAMETER INFORMATION Menu, select ‘‘SRS FLBKLSW'', and read the HDS indicated.

Is ‘‘ON'' indicated?


YES - Open in between the No. 1 terminal of left side seat belt buckle switch and body ground.n


NO - Open in between the No. 2 terminal of left side seat belt buckle switch and No. 11 terminal of SRS unit connector B (28P).n

30.From the Main Menu on the HDS, select SRS, then PARAMETER INFORMATION. In the PARAMETER INFORMATION Menu, select ‘‘SRS PASS'', and read the HDS indicated.

Is ‘‘ON'' indicated?


YES - Go to 34.


NO - Go to 31.


31.Disconnect the floor wire harness 2P connector from the front passenger's seat sitting switch.

 

32.Install a jumper wire between the No. 1 terminal and the No. 2 terminal of the floor wire harness 2P connector.

33.From the Main Menu on the HDS, select SRS, then PARAMETER INFORMATION. In the PARAMETER INFORMATION Menu, select ‘‘SRS PASS'', and read the HDS indicated.

Is ‘‘ON'' indicated?


YES - Faulty front passenger's seat sitting switch.n


NO - Open in the floor wire harness; replace the floor wire harness.n

34.Check the seat belt reminder light.

Does the seat belt reminder light stay on?


YES - Faulty gauge control module (tach).n


NO - Faulty SRS unit or poor connection at SRS unit connector B (28P) and SRS unit or poor connection at front passenger's seat belt sitting switch 2P connector and front passenger's seat sitting switch. Check the connection; if connection is OK and DTC is not indicated, replace the SRS unit.n
