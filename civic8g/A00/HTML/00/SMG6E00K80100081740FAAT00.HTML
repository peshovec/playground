DTC Troubleshooting: 74

DTC 74:  Yaw Rate Sensor (Software)


1.Turn the ignition switch ON (II).

2.Check the YAW RATE S in the VSA DATA LIST with the HDS.

Is it indicated within ±5 °/s?


YES - Go to 3.


NO - Check the installation of the yaw rate-lateral acceleration sensor. If the installation is OK, replace the yaw rate-lateral acceleration sensor.n


3.Clear the DTC with the HDS.

4.Test-drive the vehicle around a number of corners.

5.Check for DTCs with the HDS.

Is DTC 74 indicated?


YES - Go to 6.


NO - Intermittent failure, the system is OK at this time. The most probable cause is that vehicle might have spun around on a poor road surface.n


6.Turn the ignition switch OFF.

7.Substitute a known-good yaw rate-lateral acceleration sensor.

8.Clear the DTC with the HDS.

9.Test-drive the vehicle around a number of corners.

10.Check for DTCs with the HDS.

Is DTC 74 indicated?


YES - Replace the VSA modulator-control unit.n


NO - Replace the original yaw rate-lateral acceleration sensor.n
