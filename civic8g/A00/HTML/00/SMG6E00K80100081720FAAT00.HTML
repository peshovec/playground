DTC Troubleshooting: 72

DTC 72:  Steering Angle Sensor (Software)


1.With the vehicle on the ground, set the front wheels in the straight ahead driving position.

2.Turn the ignition switch ON (II).

3.Check Z-PHASE in the VSA DATA LIST with the HDS.

Is there about 1.0 V or less with the steering wheel straight ahead?


YES - Go to 4.


NO - Check the installation of the steering angle sensor in the combination switch body.n


4.Check PHASE-A STATE and PHASE-B STATE in the VSA DATA LIST with the HDS.

Is there voltage alter with turning the steering wheel very slowly?


YES - Go to 5.


NO - Check the installation of the steering angle sensor in the combination switch body.n


5.Check for wheel alignment.

Is the wheel alignment within the specification?


YES - Intermittent failure, the system is OK at this time. The most probable cause is that vehicle have run on an extreme canted road.n


NO - Make sure the suspension is not modified, then and adjust the wheel alignment correctly. After adjusting, test-drive the vehicle and retest.n
