DTC Troubleshooting: 75

DTC 75:  Lateral Acceleration Sensor (Joint Failure)


1.Put the vehicle on a level surface.

2.Turn the ignition switch ON (II).

3.Check the LATERAL ACCELERATION SENSOR in the VSA DATA LIST with the HDS.

Is it indicated within ±1 m/s2?


YES - Go to 4.


NO - Check the installation of the yaw rate-lateral acceleration sensor. If the installation is OK, replace the yaw rate-lateral acceleration sensor.n


4.Clear the DTC with the HDS.

5.Test-drive the vehicle around a number of corners.

6.Check for DTCs with the HDS.

Is DTC 75 indicated?


YES - Go to 7.


NO - Intermittent failure, the system is OK at this time. The most probable cause is that vehicle have run on an extreme canted road.n


7.Turn the ignition switch OFF.

8.Substitute a known-good yaw rate-lateral acceleration sensor.

9.Turn the ignition switch ON (II) .

10.Clear the DTC with the HDS.

11.Test-drive the vehicle around a number of corners.

12.Check for DTCs with the HDS.

Is DTC 75 indicated?


YES - Replace the VSA modulator-control unit.n


NO - Replace the original yaw rate-lateral acceleration sensor.n
