Keyless/Power Door Locks/Security Alarm System (MICU) Input Test

1.Turn the ignition switch OFF.

2.Remove the right or left kick panel.

3.Disconnect the under-dash fuse/relay box connectors.

NOTE: All connector views are wire side of female terminals.

 

4.Inspect the connector and socket terminals to be sure they are all making good contact.

  • If the terminals are bent, loose or corroded, repair them as necessary, and recheck the system.
  • If the terminals are OK, go to 5.

5.With the connectors still disconnect, make these input tests at all connectors.

  • If any test indicates a problem, find and correct the cause, then recheck the system.
  • If the input tests prove OK, go to 6.

6.Reconnect the under-dash fuse/relay box connectors then make these input tests at the connector.

  • If any test indicates a problem, find and correct the cause, then recheck the system.
  • If all the input tests prove OK, the MICU must be faulty; replace the under-dash fuse/relay box.
