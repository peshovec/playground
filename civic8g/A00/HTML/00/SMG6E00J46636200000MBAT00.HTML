Registration for Immobilizer System

NOTE: As the transponder is combined with the keyless transmitter, so when the transponder is registered by the HDS, the keyless transmitter programming is completed automatically.

1.Turn the ignition switch ON (II).

2.Connect the HDS to the data link connector.

3.Select IMMOBILIZER from the SYSTEM SELECT menu.

4.Select the suitable menu from the HDS indications as follows.

NOTE: The immobilizer-keyless control unit can store up to six transponders (transmitters).

Added or replaced part Necessary operation after entering the Immobilizer Setup menu by the HDS Prepared part(s) when registered 
Replace any of the transmitters Select ‘‘KEYS'', then ‘‘REWRITE KEYS'' 
  • All registered keys (transmitters)
  • All new keys
 
Add transmitters Select ‘‘KEYS'', then ‘‘REWRITE KEYS'' 
  • All registered keys (transmitters)
  • All new keys
 
Deleting the registration of lost transmitters Select ‘‘KEYS'', then ‘‘REWRITE KEYS'' All new keys 
All keys (transmitters) are lost.
Replace all keys (transmitters). 		Select ‘‘KEYS'', then ‘‘ALL KEYS LOST'' All new keys 
The immobilizer-keyless control unit is replaced. Select ‘‘REPLACE IMMOBI UNIT'' All registered keys 
ECM is replaced. Select ‘‘REPLACE ECM/PCM'' All registered keys 
The steering lock assembly is replaced (if there are the transponder/keyless transmitters now and reuse them continuously). Select ‘‘KEYS'', then ‘‘REWRITE KEYS'' 
  • All registered keys (transmitters)
  • All new keys
 
The steering lock assembly is replaced (also all transponder/keyless transmitters are replaced and registered). Select ‘‘KEYS'', then ‘‘ALL KEYS LOST'' All new keys
