DTC Troubleshooting: B1029

DTC B1029:  Ultrasonic Signal Error


1.Clear the DTCs with the HDS.

2.Turn the ignition switch OFF, and then back ON (II).

3.Check for DTCs with the HDS.

Is DTC B1029 indicated?


YES - Go to 4.


NO - Intermittent failure, the system is OK at this time.n


4.Do the ultrasonic sensor input test, and check power supply and ground for ultrasonic sensor.

Do all of the input tests prove OK?


YES - Go to 5.


NO - If any input tests indicate a problem, find and correct them, then recheck the system.n


5.Do the alarm control siren input test, and check power supply and ground for alarm control siren.

Do all of the input tests prove OK?


YES - Go to 6.


NO - If any input tests indicate a problem, find and correct them, then recheck the system.n


6.Disconnect the under-dash fuse/relay box connector T (34P).

7.Connect the alarm control siren 4P connector No. 3 terminal and body ground with the jumper wire.

 

8.Check for continuity between the under-dash fuse/relay box connector T (34P) No. 15 terminal and body ground.

 

Is there continuity?


YES - Go to 9.


NO - Repair an open in the wire between the MICU and the alarm control siren.n

9.Disconnect the jumper wire from the alarm control siren 4P connector.

10.Check for continuity between the under-dash fuse/relay box connector T (34P) No. 15 terminal and body ground.

 

Is there continuity?


YES - Repair a short in the wire between the MICU and the alarm control siren.n


NO - Faulty alarm control siren.n
